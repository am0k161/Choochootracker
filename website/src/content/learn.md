The **field guide** walks you through the interface with screenshots and animated examples. Start there if you're meeting ChooChooTracker for the first time.

The **user manual** is the reference for instruments, effects, commands and settings. Keep it nearby when you want to go deeper.

Never used a tracker? Get ready for a bit of a learning curve. You may want to watch quickstart guides from other similar trackers (LSDJ, ChipNomad, LittlePiggyTracker, PocketTracker, etc.).
